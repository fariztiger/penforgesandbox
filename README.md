# KodPensel Studio 2.0 beta

Mobile-friendly HTML/CSS/JS editor, sandboxed preview, console, project JSON backup/restore, developer About, and PWA offline shell.

Deploy root directory to Netlify. On iPhone, use Safari Share > Add to Home Screen. PWA offline works only after successful online load. Existing original `kodpensel.html` is preserved.

Current limits: project is HTML/CSS/JS tabs (not yet multi-file tree); draft stored in localStorage; CodeMirror, GitHub sync and SSH are not yet implemented. Back up projects regularly.
